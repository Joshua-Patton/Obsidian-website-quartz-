If a field F is a subfield of E, then E is an extension of F. We notate $E/F$

- This induces a vector field, of E over F. 
- The **dimension** is the dimension of the vector field and is denoted $[F:E]$
- an element is **algebraic** if it's the root of some field polynomial 


# types of extensions
- **Proper Extension:** An extension $L/K$ where $K\subsetneq L$.
- **Simple Extension:** An extension generated by a single element: $L=K(\alpha)$.
- **Finitely Generated Extension:** An extension generated by finitely many elements:
	  - $L=K(\alpha_1,\ldots,\alpha_n)$.

- **Finite Extension:** An extension $L/K$ where $L$ is finite-dimensional as a vector space over $K$:
	  - $[L:K]=\dim_K L<\infty$.
	  - Every finite extension is algebraic.

- **Infinite Extension:** An extension with:
	  - $[L:K]=\infty$.

- **Algebraic Extension:** An extension $L/K$ where every $\alpha\in L$ is [[algebraic]] over $K$:
	  - For every $\alpha\in L$, there exists some nonzero $f(x)\in K[x]$ such that $f(\alpha)=0$.

- **Transcendental Extension:** An extension $L/K$ containing at least one element $\alpha\in L$ that is transcendental over $K$:
  - There is no nonzero $f(x)\in K[x]$ such that $f(\alpha)=0$.


- **Separable Extension:** An algebraic extension $L/K$ where the minimal polynomial of every $\alpha\in L$ over $K$ has no repeated roots.

- **Inseparable Extension:** An algebraic extension containing an element whose minimal polynomial over $K$ has repeated roots.
  - This phenomenon can only occur in characteristic $p>0$.

- **Purely Inseparable Extension:** An algebraic extension $L/K$ of characteristic $p>0$ such that for every $\alpha\in L$:
  - $\alpha^{p^n}\in K$
  - for some $n\geq 0$.

- **Normal Extension:** An algebraic extension $L/K$ such that every irreducible polynomial $f(x)\in K[x]$ having one root in $L$ splits completely into linear factors over $L$.

- **Galois Extension:** An algebraic extension $L/K$ that is both normal and separable:
  - Galois $\iff$ Normal + Separable.

- **Splitting Field:** The smallest extension $L/K$ in which a given polynomial $f(x)\in K[x]$ splits completely into linear factors.

- **Algebraic Closure:** An algebraic extension $\overline K/K$ such that $\overline K$ is algebraically closed.
  - Every nonconstant polynomial in $\overline K[x]$ has a root in $\overline K$.

- **Degree of an Extension:** The dimension of $L$ as a vector space over $K$:
  - $[L:K]=\dim_K L$.

- **Tower Law:** If $K\subseteq L\subseteq M$ and the relevant degrees are finite:
  - $[M:K]=[M:L][L:K]$.
